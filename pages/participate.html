How to Participate

To participate in this challenge, you need to download the provided starter files and submit a Python model implementation.

1. Download the Starter Files

Download the following folders from the competition page:

  • ingestion_program/
  • dev_phase/input_data/
  • solution/

After downloading, make sure ingestion_program and solution are located at the same level in your project directory.

Example structure:

project_folder/
│
├── ingestion_program/
│   └── ingestion.py
├── dev_phase/
│   └── input_data/
│        ├── train_features.csv
│        ├── test_features.csv
│        └── private_test_features.csv
└── solution/
    └── submission.py

2. Implement Your Model

Your task is to modify the file: solution/submission.py

Inside this file, you should:

  • Define your data preprocessing pipeline
  • Define your machine learning model

The ingestion program will automatically:

  1. Load your model from submission.py
  2. Train it on the training data
  3. Evaluate it on the test sets

3. Run the Ingestion Program Locally

Once your model is implemented, you can test your solution locally by running the ingestion program. From the project root directory, run:

python ingestion_program/ingestion.py \
    --data-dir input_data/ \
    --output-dir ingestion_res/ \
    --submission-dir solution/
This command will generate a zipped file solution.zip inside the ingestion_res/ folder.
